# Beauty Booking Platform 💅

A web application for discovering beauty and nail service providers and managing appointments online.

## 🌐 Live Demo

[Open the Beauty Booking Platform](https://lazbeauty.github.io/beauty/)

## 📌 About the Project

Beauty Booking Platform is a responsive web application designed to make booking beauty and nail services easier.

Clients can browse service providers, view their profiles and services, and manage their appointments. Beauty service providers can create and manage their profiles, services and bookings.

The project was developed as a practical frontend/full-stack project to gain experience with modern web development, authentication, databases and real-time application features.

## ✨ Features

* 👤 User registration and authentication
* 💅 Beauty and nail service listings
* 🏪 Service provider profiles
* 📅 Appointment booking
* 🔄 Appointment status management
* ❌ Appointment cancellation
* 👩‍💼 Separate client and provider functionality
* 📱 Responsive design for desktop and mobile
* ⚡ Real-time data updates
* 🗄️ Supabase database integration

## 🔐 Backend & Database

The application uses **Supabase** for authentication, database services and real-time functionality.

Supabase provides the PostgreSQL database and authentication layer used by the application.

## 📱 Responsive Design

The application is designed to work across different screen sizes, including desktop, tablet and mobile devices.
