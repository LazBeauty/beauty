# Termin — MVP

Реален веб-сајт за закажување услуги (нокти, педикир, масажа...). Без плаќање сеуште — тоа се додава подоцна со Stripe кога ќе имаш фирма.

## 1. Supabase (базата)

1. supabase.com → Sign up → **New project** (регион Frankfurt/EU Central)
2. Кога проектот е готов → лево мени → **SQL Editor** → New query
3. Копирај го целиот `supabase-schema.sql` од овој проект и стисни **Run**
4. Лево мени → **Project Settings → API** → таму ги гледаш:
   - `Project URL` → тоа е `VITE_SUPABASE_URL`
   - `anon public` клуч → тоа е `VITE_SUPABASE_ANON_KEY`

## 2. Локално тестирање (пред да објавиш)

```bash
npm install
cp .env.example .env.local
# отвори .env.local и внеси ги вредностите од Supabase
npm run dev
```

Отвора на `http://localhost:5173`.

## 3. Објавување (Vercel)

1. Направи **приватен** repo на GitHub и пушни го овој код (истиот workflow: `git add .` → `git commit -m "..."` → `git push`)
2. vercel.com → Sign up со GitHub → **Add New Project** → избери го repo-то
3. Во чекорот за **Environment Variables** внеси ги истите две вредности (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)
4. **Deploy**

Vercel ти дава линк од типот `termin-app.vercel.app`. Твоето GitHub име нигде не се гледа.

## 4. Сопствен домен (по желба, за целосна анонимност)

Купи домен (Namecheap, ~10€/год) → во Vercel: Project → Settings → Domains → додади го домен и следи ги инструкциите (се менуваат DNS записи кај продавачот на домен).

## Како функционира моментално

- **Давател** прави профил (име, салон, град, услуги+цени, PIN за најава од друг уред) — снимено во Supabase
- **Клиент** пребарува по град/услуга/име, испраќа барање за термин (име+телефон, услуга, датум, час)
- Барањето стигнува кај давателот во "Барања" таб → прифаќа или одбива
- Сè е зачувано реално во базата, работи од секаде без да треба Claude

## Што недостасува / следни чекори

- Календар со точно кои термини се слободни (сега клиентот бира од фиксна листа часови)
- Известувања (SMS/email кога стигнува ново барање)
- Плаќање/претплата (Stripe) — додава се кога ќе имаш фирма
- Посилна автентикација (сега е само PIN код, доволно за MVP тест)
